# Changelog

Todos los cambios relevantes de este proyecto se documentan en este archivo.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y el proyecto usa
[Versionado Semántico](https://semver.org/lang/es/).

## [1.0.0] - 2026-10-24

### Añadido

- Autenticación con Supabase y protección de rutas.
- Dashboard con eventos en curso, próximos eventos, saldo pendiente de personal y ganancia mensual.
- CRUD de eventos con estados, filtros, búsqueda y paginación.
- Catálogo de áreas operativas y configuración de áreas por evento.
- Asignación de personal con modalidad de pago individual o por área.
- Registro y liquidación de pagos al personal, con historial por asignación.
- Gestión de cobros del cliente y gastos operativos.
- Resumen financiero por evento y por persona basado en vistas SQL.
- Catálogo de personal con tarifas, roles y estado activo.
- Interfaz responsive con PrimeVue, Tailwind CSS y notificaciones de error.
- Documentación del modelo de datos, guía de instalación y configuración de despliegue en Vercel.
- Integración continua con GitHub Actions (verificación de tipos y build).
